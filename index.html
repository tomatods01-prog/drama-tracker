A little help

On iPhone: open your GitHub Pages website in Safari. Use Share (or More → Share), then Add to Home Screen. Turn on Open as Web App if shown.

Your data: changes save on this device, in this browser. There is no account or automatic sync. Use Backup JSON, keep the file in Files or iCloud Drive, then Restore on another device.

Upgrading from v3: your saved library carries over on the same site and browser. Starter titles are added only on the first visit. A title v3 already brought back needs deleting once in v4.

Reordering: choose Your order and clear search. Use the up/down arrows on iPhone, or drag a row on desktop.

Refreshing v4: reload your existing website. If an old bookmark ends in drama-tracker-v3.html, upload the updated file with that name too. Keep a backup before changing browsers or Home Screen installations.
